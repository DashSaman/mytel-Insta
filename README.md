# Mytel Instagram Animated Series

پروژه سریال سه‌بعدی مای‌تل برای اینستاگرام. نسخه اولیه؛ داستان‌ها پیش‌نویس و قابل بازنگری‌اند.

- فصل اول: «الو... عشقم پشت خطه!»؛ ۳۰ قسمت، ۴۸ تا ۵۶ ثانیه، هفته‌ای ۳ ریلز.
- قهرمانان: آقای زنگی و سیمو؛ نوستالژی دهه ۱۳۷۰ تا ورود به مجتمع درمانی بزرگ.
- بدون تبلیغ مستقیم در آغاز؛ هر قسمت شوخی مستقل و تعلیق قسمت بعد.
- تولید: Google Flow، تصاویر مرجع ثابت، کلیپ‌های کوتاه و تدوین عمودی 9:16.
- لوگوی واقعی مای‌تل باید از فایل تأییدشده برند وارد شود؛ هیچ لوگوی ساخته‌شده با AI مجاز نیست.

برای تصاویر و ویدیوها، فایل‌های اصلی باید بعداً به `assets/` افزوده شوند؛ هیچ فایل تصویری هنوز در مخزن آپلود نشده است.
